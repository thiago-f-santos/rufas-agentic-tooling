# RuFaS Graph Memory Brain & Correlation Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an embedded graph memory brain in KùzuDB (`kuzu`) that maps simulation inputs to outputs, maintains full parameter/variable metadata catalogs, computes statistical correlations across multiple runs, exports on-demand Obsidian knowledge graphs, and equips AI agents with a dedicated `rufas-brain-specialist` skill.

**Architecture:** Embedded KùzuDB property graph engine (`tools/rufas_brain.py`) storing a dual-layer graph (Structural Biophysical Ontology + Empirical Simulation History). Integrates with RuFaS output CSVs, computes Pearson/Spearman correlation statistics with p-values, exposes OpenCypher querying, generates linked Markdown notes with Dataview DQL for Obsidian, and installs the `rufas-brain-specialist` agent skill.

**Tech Stack:** Python 3.14, KùzuDB (`kuzu>=0.11.3`), SciPy (stats), Pandas, NumPy, pytest, Markdown / YAML frontmatter.
